# Announcement Dialog

Displays a branded IT announcement to the logged-in user via jamfHelper.

Presents a utility-window message with a configurable title, icon, body and button. Intended for maintenance notices, required-action prompts and general IT communications pushed from a policy.

Edit the `MsgTitle`, `MsgBody`, `MsgIcon` and `MsgButton1` variables at the top of the script, or adapt them to Jamf parameters if you want one script serving many messages.

**Requirements:** jamfHelper (ships with the Jamf binary).
